# Architektūros katalogo sistema

## Projekto uždavinys

Šio projekto tikslas – Sukurti architektūros objektų katalogo sistemą, kurioje būtų pateikiama informacija apie pastatus ir architektūrinius stilius, palengvinti jos paiešką architektūra besidomintiems žmonėms bei suteikti galimybę dalintis savo įspūdžiais.

Sistemoje numatyti trys naudotojų tipai ir jų funkcijos:

**Svečias:** gali peržiūrėti architektūrinių stilių sąrašą, atlikti pastatų paiešką bei filtravimą pagal stilių ar miestą, peržiūrėti kitų lankytojų komentarus.

**Naudotojas:** gali naudotis visomis svečio funkcijomis, taip pat rašyti ir redaguoti savo komentarus.

**Administratorius:** atsakingas už stilių ir pastatų pridėjimą, redagavimą bei šalinimą ir komentarų moderavimą.

## Technologijos

**Back-End:** C# .NET REST API (sluoksninė architektūra)

**Duomenų bazė:** MySQL (Entity Framework Core)

**Front-End:** React
